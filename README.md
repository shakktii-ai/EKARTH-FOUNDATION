# Ekarth Foundation - Official Web Application

**Ekarth Foundation** — *Empower. Educate. Elevate. | Supporting Education. Nurturing Futures.*

Ekarth Foundation is a Section 8 non-profit organization (CIN: `U88900PN2025NPL246146`), registered under Section 12A & 80G of the Income Tax Act, based in Pune, Maharashtra, India. The foundation works toward educational scholarships, school kits distribution, hospital medical aid, and youth skill empowerment.

---

## 🎯 Core Focus Areas & Programs
1. **Education Scholarships**: Up to ₹5,000 per student disbursed directly to educational institutions.
2. **Hospital Donations & Medical Aid**: Essential medical equipment and aid to underserved patients.
3. **Talent Competitions**: Identifying and fostering academic, creative, and athletic skills.
4. **Skill Development**: Vocational training, digital literacy, and job readiness for youth.
5. **Education Kits Distribution**: School bags, stationery, and books for underprivileged students.
6. **Institutional Tie-Ups**: Transparent partnerships with schools and colleges.
7. **Career Counselling**: Guiding youth toward sustainable career paths.
8. **Health Awareness Camps**: Preventative healthcare screenings and wellness awareness.

## 🚀 Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 🛠️ Build & Verification

```bash
npm run build
```
